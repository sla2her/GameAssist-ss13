# Пульт

Одно окно для двенадцати программ: **Алхимик**, **Терминал Брига**, **Папирус**, **Инженер**, **Кухня и бар**, **Химзавод**, **Персонаж** (редактор персонажа), **Симулятор Схем** (конструктор интегральных схем), **Панель АВД** (нарушения НРП и рапорты), **Глава Персонала**, **Панель ИИ** и **Панель Капитана** (Панель Командования).

`Пульт.exe` — один файл (~2,3 МБ), без интернета и установки. Нужен Microsoft Edge WebView2 (в Windows 10/11 уже есть).

`Пульт.apk` — то же для Android 7.0 и новее (см. раздел «Android»).

## Как пользоваться

- При запуске открывается **радиальное меню**: нажмите на сектор, чтобы открыть приложение.
- Открытые приложения не закрываются при переключении: всё введённое остаётся на месте.
- Панель сверху: кнопка меню, иконки всех приложений для быстрого переключения, режим окна, 📌 «поверх всех окон».
- **Два режима окна** (переключатель в центре меню и на панели):
  - **Расширенный** — обычное большое окно, как у отдельных программ.
  - **Компактный** — узкое окно (~460 px) у края экрана со всеми теми же функциями: вкладки и ленты
    прокручиваются колесом мыши, колонки Папируса «Блоки / Лист / Код» становятся вкладками,
    у Химзавода поле сверху, а инструменты и инспектор под ним.
  - Размер и положение окна запоминаются отдельно для каждого режима.
- Клавиши: `Alt+1…9` — приложения в порядке панели, `Alt+-`, `Alt+=`, `Alt+\` — Глава Персонала, Панель ИИ, Панель Капитана, `Alt+0` — меню, `Alt+M` — режим,
  `Alt+P` — поверх окон, `Esc` — закрыть меню.

### Инженер

Веб-версия оверлея `engineer-helper` с теми же инструкциями из `..\engineer-helper\guides.json`.
В узком окне виден только текущий шаг, как в оверлее, а в широком — ещё список инструкций и все шаги.

Хоткеи из `guides.json` (по умолчанию `F7`/`F8` — шаг, `F6`/`F9` — инструкция, `F10` — скрыть/показать окно)
Пульт занимает глобально, как и старый оверлей: они работают, пока активно окно игры, и пропадают для игры, пока Пульт запущен.
Клавиши занимаются при первом открытии Инженера. Нажатый шаговый хоткей сам переключает Пульт на Инженера.
Если клавиша занята другой программой (например, запущен старый `engineer.pyw`), Инженер пишет «Не удалось занять: …».
Внутри окна работают ещё `←`/`→`, `PageUp`/`PageDown` и колесо мыши по карточке шага.
Прозрачность окна из старого оверлея не перенесена.

### Симулятор Схем

Конструктор интегральных схем (integrated electronics) из сборки BlueMoon: схема собирается из блоков, а не пишется кодом.

- Блоки (компоненты) перетаскиваются из списка на поле или добавляются нажатием. Провода тянутся от кружка выхода к кружку входа:
  кружки — данные, ромбы — импульсы. Нажатие на значение входа задаёт константу, ПКМ по пину — отсоединить.
- Справа печатается **код для принтера схем**: в принтере «Load program» → вставить код → печать. Это тот же формат,
  что сохраняет анализатор схем, поэтому «Вставить код…» открывает и чужие схемы, и схемы из игры.
- Сложность и место считаются по выбранному корпусу; предупреждает о компонентах, которым нужен улучшенный принтер,
  и о тех, что работают только в дроне.
- **Симуляция** запускает схему прямо в Пульте: кнопки, цифровые и текстовые панели, экраны, лампы, таймеры и тикеры,
  арифметика, логика, память, мультиплексоры, конвертеры, списки. Сканеры, манипуляторы, химия и атмос не моделируются — им нужен мир игры.
- В «Примерах» — счётчик нажатий, мигалка, кодовый замок и калькулятор.

Каталог компонентов (`circuits/catalog.js`) собран из исходников MOLOT-BlueMoon-Station: `node circuits/update-catalog.mjs`.

### Панель АВД

Помощник Агента Внутренних Дел по документу «Нормы рабочих процедур» — сектор «Юридический отдел» в меню, `Alt+9`.

- **Нарушения** — НРП по отделам: Сервис, Снабжение, Медотдел, ОИР, Инженеры, СБ, Командование, Юр. отдел, Силиконы,
  уровни тревоги и процедуры КЗ. Кнопка отдела открывает его НРП с фильтром по должностям; поиск ищет сразу по всем отделам.
  Пункты разделены на «обязан», «запрещено», «положения»; «Всё» показывает ещё права должностей.
- «+ В рапорт» собирает нарушенные пункты в панель рапорта: нарушитель, должность, мера — и «Оформить рапорт».
- **Рапорт** — документы АВД: рапорт о нарушении НРП, жалоба / заявление, протокол расследования, акт об отстранении,
  отмена вердикта, запрос информации, ордер на обыск. Текст, Markdown или SS13 по профилю Папируса, кнопка «В Папирус».
- **Полномочия** — НРП АВД и Представителя Пакта, порядок работы с жалобой, политики увольнения и отстранения.
- Номера пунктов («п. 3.5») — порядковые внутри отдела (должность.пункт): в самом документе пункты не пронумерованы.

База — `avd/nrp.js`, собирается из документа: в Google Docs «Файл → Скачать → Markdown», затем
`python avd/parse_nrp.py НРП.md avd/nrp.js`.

### Панель Командования

Сектор «Командование» в меню открывает второй круг: Глава Персонала (`Alt+-`), Панель ИИ (`Alt+=`), Панель Капитана (`Alt+\`).
Это одна страница `command/index.html`: Пульт открывает её с `?only=hop|ai|cap`, и у каждой части своё сохранённое состояние.
Без параметра (в браузере) все три части — вкладки одной страницы.

- **Глава Персонала** — документы: заявка на допуск, акт выдачи, перевод / приём, увольнение / понижение, регистрация в БД
  (Текст, Markdown, SS13, «В Папирус»). Допуски отмечаются по зонам, у каждой зоны видно, чья подпись нужна: панель
  учитывает, кто из глав на станции, код тревоги, ЧС и п. 8.6 НРП ГП. Типовые наборы должностей, порядок работы,
  журнал смены («В журнал» у акта).
- **ИИ** — своды законов из НРП с разбором каждого закона, иерархия законов, клавиши и каналы, возможности ИИ,
  готовые фразы и разбор спорных ситуаций для НТ-Стандарта, Кру-Азимова и Корпоративного.
- **Капитан** — цели станции (Блюспейс-артиллерия, ДНК-хранилище, Собиратель блюспейс-частиц, Щиты станции):
  как выполнить и как засчитывается — по `code/modules/station_goals` BlueMoon; чек-лист смены, цепочка ВрИО,
  генератор объявлений и факса ЦК, уровни тревоги из НРП.

Своей базы нет: НРП берётся из `avd/nrp.js` (`../avd/nrp.js`), поэтому обновляется вместе с Панелью АВД.

### Данные

Данные хранятся в `%LOCALAPPDATA%\Pult`. Хранилище отдельное от старых версий всех программ, поэтому сами
не переедут рецепты Алхимика, шаблоны Папируса, место в инструкциях Инженера, избранное и «Мой бар» Кухни, схемы Химзавода, персонажи редактора, схема в Симуляторе Схем.
Для переноса: в Папирусе «Сохранить настройки в файл» / «Шаблоны → Сохранить в файл», в Химзаводе «Экспорт» / «Импорт», в Персонаже «Передача слота».

## Android

`Пульт.apk` ставится как обычное приложение (в настройках телефона разрешить установку из этого источника).
Внутри всё то же самое и тоже без интернета; сеть нужна только кнопкам обновления баз с GitHub.

- На телефоне всегда компактный режим, на планшете (от 600 dp) режим можно переключать.
- «Назад»: из приложения — в меню, из меню — обратно в приложение; со стартового экрана Пульт уходит в фон, не теряя введённого.
- В Инженере шаги листаются кнопками громкости (− дальше, + назад). Хоткеев F6–F10 на телефоне нет.
- «Сохранить в файл» / «Экспорт» открывают системный диалог сохранения, «Открыть файл» / «Импорт» — выбор файла.
  «Из папки…» в Химзаводе на Android не работает — используйте «Из .zip…».
- Данные телефона и компьютера не связаны; переносятся теми же экспортом и импортом.

Сборка: `powershell -ExecutionPolicy Bypass -File android\build.ps1`. Нужны портативные инструменты в `android\.tools`:
JDK 17 (`jdk-*`) и Android SDK (`sdk\build-tools\34.0.0`, `sdk\platforms\android-34`). Gradle не нужен.
Ключ подписи — `android\pult-release.jks`, пароль — в `android\pult-release.password.txt`. Храните оба:
обновить установленный Пульт можно только APK, подписанным тем же ключом.

## Устройство

| Путь | Что это |
| --- | --- |
| `web/index.html`, `shell.css`, `shell.js` | Оболочка: меню, панель, режимы, хоткеи Инженера |
| `web/compact/*.css`, `papirus.js` | Компактная вёрстка приложений (подключается оболочкой) |
| `engineer/index.html` | Веб-версия Инженера (исходник; в `web/apps/` попадает копия) |
| `circuits/` | Симулятор Схем: `app.js` — редактор, `sim.js` — симулятор, `catalog.js` — компоненты, `update-catalog.mjs` — сборка каталога |
| `avd/` | Панель АВД: `index.html` — приложение, `nrp.js` — база НРП, `parse_nrp.py` — сборка базы из документа |
| `command/` | Панель Командования: `index.html` — приложение (НРП берёт из `avd/nrp.js`) |
| `web/apps/` | Копии приложений, создаются `sync-apps.ps1` — руками не править |
| `native/Pult.cs` | Окно WinForms + WebView2, отдаёт `web/` из памяти exe, занимает хоткеи |
| `native/build.ps1` | Сборка `Пульт.exe` |
| `android/src/…/MainActivity.java`, `AndroidManifest.xml` | Приложение Android: WebView, отдаёт `web/` из APK, мост для файлов и буфера |
| `android/build.ps1` | Сборка `Пульт.apk` |

Сами приложения правятся в своих папках (`..\Алхимик`, `..\brig-terminal`, `..\Папирус`, `..\engineer-helper\guides.json`,
`..\ss13-kitchen`, `..\Химзавод`, `..\Персонаж`) и собираются как раньше.

## Сборка

```
powershell -ExecutionPolicy Bypass -File native\build.ps1
```

Скрипт сначала забирает свежие `Алхимик.html`, `brig-terminal\app\`, файлы Папируса, `guides.json` Инженера,
`BlueMoon-Kitchen.html`, `Химзавод.html`, `Персонаж.html`, `circuits\` и `avd\`, затем компилирует exe встроенным в Windows `csc`.

Посмотреть в браузере: `npx http-server web -p 5180` и открыть http://localhost:5180 (компактный режим там показывается узкой колонкой).
